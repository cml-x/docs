==================================================
1. COMPRENDRE LE PRODUIT
==================================================

Camel X est une plateforme modulaire composée de plusieurs micro-applications indépendantes.

Chaque micro-application apporte une capacité spécifique autour de l'intégration, de l'API Management, de l'identité, de la sécurité, de l'infrastructure et de l'observabilité.

La documentation ne doit donc PAS présenter Camel X comme une seule application monolithique.

Elle doit présenter :

CAMEL X
│
├── Project Manager
├── Runtime Manager
├── API Manager
├── Auth Manager
├── Access Manager
├── Environment Manager
└── Monitoring

Ces composants sont indépendants mais complémentaires et peuvent être utilisés ensemble pour construire, sécuriser, déployer, exécuter et superviser des intégrations.

L'objectif de la documentation est de permettre à un utilisateur de comprendre :
- ce qu'est Camel X ;
- à quoi sert chaque micro-application ;
- comment les micro-applications fonctionnent ensemble ;
- quelle application utiliser selon son besoin ;
- comment construire une intégration de bout en bout ;
- comment sécuriser une intégration ;
- comment la déployer ;
- comment l'exécuter ;
- comment l'observer et la superviser.

==================================================
2. POSITIONNEMENT DE CAMEL X
==================================================

Présenter Camel X comme une plateforme d'intégration modulaire permettant de :

- concevoir des intégrations Apache Camel ;
- utiliser les composants Apache Camel ;
- créer des workflows et des flux d'intégration ;
- créer des releases prêtes à être déployées ;
- gérer les environnements d'exécution ;
- déployer et exécuter les flux ;
- exposer des API ;
- sécuriser les API et applications ;
- gérer les utilisateurs et leurs permissions ;
- appliquer des politiques IAM/RBAC ;
- superviser les flux et services ;
- observer l'activité de la plateforme.

Ne pas inventer de fonctionnalités qui ne sont pas explicitement décrites dans cette documentation.
