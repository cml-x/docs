Monitoring Manager is the observability surface of the platform. It lets you stand up
[OpenObserve](https://openobserve.ai) dashboards for your project and environment in minutes, and
links out to the underlying OpenObserve instance for logs, metrics and traces.

![Observability overview](/img/monitoring/observability.svg)

## Create your first dashboard

When a project has no dashboards yet, the page leads directly with a **template gallery** instead
of an empty list — a set of ready-made dashboards you can preview (name, description, included
files, a rendered README) and instantiate with one click, rather than building one from scratch.

Selecting a template fetches each dashboard definition it includes and creates it in the project's
`default` OpenObserve folder.

From there, see [Dashboards](/monitoring/home) to manage what you've created, or jump straight to
[Logs](/monitoring/logs), [Metrics](/monitoring/metrics) or [Traces](/monitoring/traces).
