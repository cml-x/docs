Browse every dashboard saved in your project's `default` OpenObserve folder.

## What you can do

- **Search** dashboards by title or description.
- Each card **links out** (new tab) to the live dashboard in OpenObserve, already scoped to your
  current project and environment — you never have to re-pick the org/stream by hand.
- Start from a **template** instead of building one from scratch — see
  [Getting Started](/monitoring/getting-start).

Links are built from a project + environment + dashboard-id URL template, so they always resolve
to the right OpenObserve scope for whichever environment you have selected.
