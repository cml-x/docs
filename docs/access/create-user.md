Step-by-step version of the user-creation capability described in [Users](/access/users).

## Steps

1. In Access Manager, open **Users** and create a new user with their name, email and phone.
2. Optionally assign an **organization-level admin role**: Owner, Viewer, User Manager, Permission
   Editor, Project Editor, or Project Creator — each scoped to a specific set of admin
   capabilities. Leave this unset for a regular user with no admin capabilities.

## Result

The user exists at the organization level, but has **no project access yet** — that's granted
separately. Continue to
[Assign Roles & Permissions](/access/assign-roles-and-permissions) to give them access to a
specific project.
