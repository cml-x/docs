A **Connected App** is a machine service account for API/M2M authentication — for scripts,
pipelines or external systems that need to call the platform's APIs without a human user.

## What you get

Each Connected App gets, managed from its own detail page:

- A generated **client secret**.
- **Personal access tokens**.
- **JSON Web Keys** (JWKs), with configurable expiration.

Use a Connected App whenever automation needs to authenticate against the platform — CI/CD
pipelines, external integrations, or scheduled jobs.
