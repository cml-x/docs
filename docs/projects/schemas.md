The schema registry stores API and data contracts independently of any single project's Git
history, so they can be versioned and reused across integrations.

## What you can do

- **Create, browse and search** schema artifacts, grouped per project.
- Supported formats: **OpenAPI**, **AsyncAPI**, **JSON Schema**, and **Avro**.
- Opening a schema launches a **dedicated schema editor**.
- Schemas are versioned on their own — they don't need to move in lockstep with the Git repository
  that originally defined them.
